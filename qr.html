iPhone

  1. Open the Camera and point it at the code.
  2. Tap the yellow link that appears.
  3. Optional: in Safari tap Share → Add to Home Screen.

Android

  1. Open the Camera (or Google Lens) and point it at the code.
  2. Tap the link that appears.
  3. Optional: in Chrome tap ⋮ → Add to Home screen.

Club tablets (organizer, court and display tablets)

The full tablet app (tablet sync, court scoring, Excel files) is an Android APK.

Download MatchMaker.apk
  1. Open the downloaded file → allow installing from this source → Install.
  2. If Play Protect warns: More details → Install anyway.
  3. It updates itself after that — no need to download it again.
