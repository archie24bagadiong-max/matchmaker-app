# Match Maker - JAMREIBIZ Badminton Club

Update source for the Match Maker Android app.

- `index.html` – the app
- `version.json` – latest version number; the app checks this on start and offers an update when it is higher than its own `APP_VERSION`.
- `DOCS.md` – full documentation of the app
